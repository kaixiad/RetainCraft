## 发现的严重 Bug（已全部修复）

### Bug 1: FSRS rating 映射错误 (CRITICAL)
- **文件**: `scripts/srs.py` line 953
- **问题**: `RATING_TO_INT = {"again": 1, ...}` 但系统使用 `"wrong"`，导致 `"wrong"` 落入 default=3（Good）
- **后果**: 答错时 rating 被当作 Good(3) 处理
- **修复**: `"wrong"→1` 替代 `"again"→1`
- **回归测试**: `test_fsrs_wrong_rating_uses_forgetting_path`

### Bug 2: FSRS 遗忘路径条件错误 (CRITICAL)
- **文件**: `scripts/srs.py` line 981
- **问题**: `rating == "again"` 字符串比较永远不匹配（系统用 `"wrong"`）
- **后果**: `fsrs_stability_after_forgetting` 永远不会被调用
- **修复**: `rating_int == 1`（整数比较）

### Bug 3: FSRS 稳定性永不增加 (CRITICAL)
- **文件**: `scripts/srs.py` line 976
- **问题**: review 后 R 被重置为 1.0，下次 review 时用 R=1.0 计算稳定性增量
- **数学原因**: `(exp(w10*(1-R))-1)` 当 R=1.0 时 = `(exp(0)-1)` = 0
- **后果**: 连续 good review 时稳定性不变（间隔不增长）
- **修复**: 使用 R=0.9（目标 retention）作为稳定性更新的默认值
- **验证**: good→good 后 interval 从 3→11，stability 从 3.17→11.14 ✅
